### 技术栈概览

| 层级 | 技术 | 版本/说明 |
|------|------|-----------|
| 前端框架 | Vue 3 (Composition API) | Web端 + 管理端 + 小程序 |
| 构建工具 | Vite | Web端 + 管理端 |
| UI组件库 | Element Plus | 管理后台 |
| 样式 | Sass + Animate.css | Web门户 |
| 后端框架 | Spring Boot 3.2.6 | 微服务基础 |
| 微服务治理 | Spring Cloud Alibaba 2023.0.1 | Gateway + Nacos + Sentinel |
| ORM | MyBatis Plus 3.5.5 | 雪花算法ID + 逻辑删除 |
| 数据库 | MySQL 8.0 + Redis + MongoDB | 业务数据 + 缓存 + AI对话 |
| 认证 | Spring Security + JWT (jjwt 0.12.3) | BCrypt + Bearer Token |
| 任务调度 | XXL-JOB 3.4.0 | 数据清理定时任务 |
| 对象存储 | 阿里云OSS | 图片/文件存储 |
| AI模型 | DeepSeek API (deepseek-v4-pro) | AI对话服务 |

### 数据流

```
浏览器/小程序 → [HTTP] → Gateway(8080) → JWT鉴权 → 路由分发
                                              ↓
              ┌────────┬──────────┬────────┬────────┬────────┐
              ↓        ↓          ↓        ↓        ↓        ↓
            Auth   Tourism   System    File      AI     Nacos(8848)
           8100     8300      8200     8400     8500
              ↓        ↓          ↓        ↓        ↓
              └────────┴──────────┴────────┴────────┴────────┘
                                   ↓
                              MySQL(3306) + Redis(6379) + MongoDB(27017)
```

## 三、填写脚本说明

共使用 **5个Python脚本** 和 **python-docx库** 完成文档填写：

| 脚本文件 | 用途 | 处理方式 |
|----------|------|----------|
| `fill_docs.py` | 主填写脚本 | 填写doc1-doc5+周报，共5份文档的基础内容 |
| `fill_docs_extra.py` | 测试文档 | 创建4.0测试计划.docx和4.1项目测试报告.docx |
| `fill_doc1_complete.py` | 完整填写1.0需求报告 | 基于content_map字典匹配段落提示词，替换为实际内容; 填表(术语/用例/优先级/变更) |
| `fill_doc1_final.py` | 补填3个遗漏章节 | 法规政策约束、文档需求、其他需求 — 查找Heading后的空段落填入 |
| `fill_doc1_fix.py` | 清理残留提示 | 遍历所有段落，将以"提示："开头的替换为引导文本或清空 |

### 填写策略

1. **段落内容替换**: 遍历所有段落，将文本与预设字典的key精确匹配，匹配成功则替换内容
2. **表格填充**: 按表索引定位(Table1-8)，按行逐个单元格写入
3. **占位符替换**: 直接替换封面中的`XXXX年XX月XX日`→`2026年06月02日`, `XXXX业务`→`景区购票业务`
4. **残留清理**: 最终遍历清除所有未被替换的"提示："开头的段落

## 六、项目核心流程总结

### 6.1 用户购票完整链路

```
[前台Web] 浏览景区列表 → 点击景区详情 → 点击"立即购票"
    → TicketModal弹窗(选数量1-10/游览日期/联系人信息)
    → 点击"立即支付"or"稍后支付"
    → [Gateway:8080] JWT鉴权 → 路由 /api/tourism/order
    → [Tourism:8300] OrderController.create()
        → 生成订单号(MKT+时间戳+4位随机码)
        → 插入tourism_order表(status=paid/pending)
    → 返回订单信息
    → [前台] 跳转"我的订单"可查看/支付/取消
```

### 6.2 收藏完整链路

```
[前台Web] 景区详情/卡片 → 点击♡收藏按钮
    → [Gateway:8080] JWT鉴权 → 路由 /api/tourism/favorite
    → [Tourism:8300] FavoriteController.toggle()
        → 检查 UNIQUE(user_id, attraction_id, deleted)
        → 未收藏: INSERT (deleted=0)
        → 已收藏deleted=1: UPDATE deleted=0 (恢复)
        → 已收藏deleted=0: 提示已收藏
    → 返回收藏状态 → [前台] ♡变♥
```

### 6.3 AI对话链路

```
[前台Web] AI对话页面输入问题 → POST /api/ai/chat
    → [Gateway:8080] JWT鉴权 → X-User-Id传递
    → [AI:8500] AiChatController.chat()
        → 查询/创建MongoDB chat_session
        → 构建messages上下文
        → 调用DeepSeek API (https://api.deepseek.com, model=deepseek-v4-pro)
        → 保存assistant回复到MongoDB
    → 返回AI回复 → [前台] 渲染Markdown消息
```

### 6.4 定时任务链路

```
[XXL-JOB Admin:8082] 定时触发
    → [Tourism执行器:9997] 每日: 清理deleted=1且超过30天的数据
    → [AI执行器:9998] 每月: 清理超过30天的AI对话历史(MongoDB)
```
